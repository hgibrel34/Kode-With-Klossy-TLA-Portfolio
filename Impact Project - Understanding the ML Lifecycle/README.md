# Understanding the ML Lifecycle

## Why this exists

I'm an Industrial and Systems Engineering student at Virginia Tech, currently
in the Break Through Tech AI/ML fellowship, working toward a Machine Learning
certificate this summer. My coding skills had gone dormant without regular
use in my coursework, so jumping into a fast-paced ML program was difficult. 
The course is structured around the ML lifecycle (from business
understanding through deployment) and taking in all of it at once was a lot to digest.

## Who this is for

Labmates/future cohorts working through the BTT ML/AI course, especially anyone
early in the lifecycle who wants to see where a concept or library fits into
the bigger picture.

## How to use this guide

- **New to the material?** Read top to bottom, each stage build on the one before it.
- **Stuck on something specific?** Jump straight to that stage using the table of contents.
- **Need a refresher?** The quick-reference table alone covers the core concept + library for each stage.
