# M1: The Unasked Question

*Creating a resource that solves an existing problem.*

**Target Skills: Resource Creation, Stakeholder Identification, Problem Solving**

## Task

I identified one technical community I mapped in my Stakeholder Audit and proactively answered a question nobody had asked yet. This artifact is a short guide explaining sensitivity analysis for a non-technical audience. I created it to turn a class concept into something practical and understandable for someone outside Operations Research, so that something useful now exists that didn't before, and at least one person besides me benefits from it.

## Process

- Defined sensitivity analysis in simple terms
- Explained how changes in model inputs, such as costs, constraints, or resources, can impact the optimal solution
- Introduced key AMPL sensitivity analysis outputs, such as shadow prices and reduced costs
- Connected these ideas to real-world decision-making scenarios

## Deliverable

This folder expands on a sensitivity analysis concept briefly introduced in class that later became a significant part of the final project. The deliverable for this module is included in this folder alongside this README, and walks through core definitions and practical applications, followed by a section applying the concept in AMPL.

A friend outside operations research reviewed this document for clarity. She found the definitions and applications easy to follow, but the AMPL section harder to understand, indicating that piece may need more context or a simpler explanation for readers unfamiliar with the tool.
